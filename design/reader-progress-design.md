# 阅读器底部控制区与全书进度条

更新日期：2026-09-29。本文记录阅读器底栏的交互与视觉规格，架构及验证入口见 [阅读器进度导航架构](reader-progress-architecture.md)。App 已接入底栏与定位流程，章节浮窗采用固定外框、文字居中的预览卡；本文件中的验收要求不表示已通过设备验证。早期样稿中的雾紫为示例色，正式颜色接入应用现有主题与动态配色。

## 1. 布局与样式

采用圆角悬浮底栏 ，进度条与工具按钮共用一个面板 ，随阅读菜单显示或隐藏 。全部颜色从当前 `MaterialTheme.colorScheme` 获取 ，沿用用户选择的预设主题 、动态配色及明暗模式 ，适配系统大字体 。底部按上一章 、书签 、目录 、设置 、下一章顺序保留五项入口 ；书签已有后续实现计划 ，当前未实现时保持禁用 ，实现后原位启用 。

| 元素 | 规格 |
| --- | --- |
| 底栏面板 | 距屏幕左右约 14 dp ，圆角 27 dp ，不透明表面色 ，轻阴影 ；面板内上 / 左右 / 下留白约 8 / 14 / 12 dp ，底部留白与系统安全区分开处理 |
| 轨道 | 高 16 dp 的胶囊 ，浅色底轨与柔和的进度填充 ，全圆角 ，无边框 ；位于按钮行上方 ，两端圆帽的圆心与滑块端点中心对齐 ，完整容纳书首与书尾的原位置点 |
| 当前滑块 | 直径 24 dp，实心圆，轻阴影，与轨道明显区分；吸附原位置时提供轻微缩放反馈 |
| 原位置点 | 直径 16 dp，与轨道等高，柔和主题色填充，无边框或阴影；保持绘制，重叠部分由后绘制的主滑块覆盖 |
| 触摸区域 | 进度操作行高 52 dp，操作区域至少 48 × 48 dp，不随视觉圆点缩小；重叠区域根据可见圆形和按下位置判定，见第 3 节 |
| 工具按钮 | 五项等宽横排 ，每项触摸宽度至少 48 dp 、高度约 60 dp ，图标约 22 dp ，下方文字约 11 sp ；全部使用透明底与一致的前景色 ，按下时显示点击反馈 ，禁用书签弱化显示 |
| 章节浮窗 | 固定在底栏上方水平居中 ，距面板约 14 dp ，胶囊外形 、圆角约 24 dp ，无尖角 ，不随滑块移动 ；固定宽度 256 dp ，可用空间不足时缩窄 ，不随章节名或百分比变化 ；覆盖正文 ，不撑高底栏 |
| 浮窗内容 | 标题 13 sp 、20 sp 行高 ，固定预留两行区域 ，标题在两行区域内水平 、垂直居中 ，长标题最多两行 、超长省略 ；高度按实际字体测量适配系统缩放 ，同一排版设置下不随标题变化 ；下方固定位置以 11 sp 、15 sp 行高单行显示全书目标百分比 ，如“61.5%” ，水平居中并采用等宽数字 ；左右内边距 16 dp 、上下 10 dp 、内容间距 5 dp ；不显示卷名或“约”前缀 |

以上尺寸以确认样稿为基准 ，Android 使用 dp / sp 适配 ，真机调整不得缩小触摸区域 。窄屏可缩减外边距与按钮间距 ，大字体允许底栏增高 ，不得压缩按钮或裁切标签 。浮窗不得超出屏幕安全边距 。轨道不显示常驻数字 ，不留数字占位行 。不显示页码 、刻度 、额外返回按钮或解释提示 。

正式配色使用主题色角色 ，以下为接入方案 ，需在各主题下验证实际对比度 ：

| 用途 | 当前主题色角色 |
| --- | --- |
| 面板表面 | `surfaceContainer` ，不透明 |
| 主要文字 | `onSurface` |
| 次要文字与普通图标 | `onSurfaceVariant` |
| 工具按钮底色 / 前景色 | 透明 / `onSurfaceVariant` ，目录无常驻强调底色 |
| 底轨 / 进度填充 | `surfaceContainerHighest` / `primaryContainer` |
| 当前滑块 | 浅色主题使用 `surfaceBright`；深色主题在 `inverseSurface` 与 `surface` 间按 10% 比例混合 |
| 原位置点 | 浅色使用 `secondary`，深色在 `secondaryContainer` 与 `secondary` 间按 60% 比例混合；均以 45% 不透明度绘制，不绘制反色内圆 |
| 章节浮窗底色 / 文字 | `surfaceContainerHigh` / `onSurface` ，背景不透明 ，百分比使用 `onSurfaceVariant` 保持次级层次 ，轻阴影 1 dp |

主题行为沿用现有 `LightNovelReaderTheme` ，底栏不单独生成色板 ，不新增配色开关 ：

- 动态配色开启且系统为 Android 12+ 时 ，使用应用已经生成的动态色板 ；关闭或系统不支持时 ，沿用现有预设主题回退逻辑 。
- 浅色预设包括默认与设计者 ，深色预设包括默认 、黑曜石与设计者 ；明暗模式沿用开启 、关闭或跟随系统的选择 。黑曜石目前仅将 `background` 与 `surface` 设为纯黑 ，底栏继续使用其容器色层次 ，不将全部浮层强制设为纯黑 。
- 阅读器自定义正文颜色 、纸张背景和背景图片保持现有作用范围 ；底栏及浮窗使用不透明的主题表面色 ，不从正文背景图片取色 ，也不直接用正文文字颜色绘制操作按钮 。
- 保留“弱底轨 、柔和填充 、清晰滑块”的关系 ，工具入口保持一致 ，不复制雾紫十六进制色值 。样稿中的雾紫 、松绿 、暖砂和一体式底栏仅用于设计比较 ，不新增相应的产品选项 。

## 2. 定位与拖动

- 滑块表示全书内容的相对位置 ，支持章内定位 。最左端为全书开头 ，最右端为最后一个可读位置 ，跨卷顺序与目录一致 。
- 目录就绪即可操作，不要求下载全书正文后才能使用。全书映射优先使用匹配当前正文与排版的页数，尚无有效结果的章节使用估算页数，完全没有样本时先等分章节。翻页模式使用实际分页结果；滚动模式按正文布局与视口高度产生参考页数，两种模式分别生成索引。
- 进入阅读时先建立估算映射，首次有效缓存加载可在尚未拖动时修正权重；首次拖动后冻结当前会话权重，新增分页结果在下次进入阅读时采用。目录更新按章节身份重建，拖动期间延后应用。字号、字体、正文区域尺寸或阅读模式变化时保留正文锚点，当前会话沿用旧权重作估算；新的排版结果正常计算并写入缓存，不当场重排全书进度。
- 正文按需加载，拖动预览不下载沿途章节，松手后加载目标章节并沿用附近章节预加载。整本下载沿用现有缓存入口与设置，不因打开阅读器而强制缓存全书。页数缓存从实际阅读与预读排版积累；当前没有独立的后台全书补算任务。
- 翻页模式定位到目标页面 ，滚动模式定位到目标正文位置 。不得将整章内的不同目标统一定位到章首 。
- 拖动期间显示章节浮窗 ，实时更新目标章节与全书位置百分比 ，正文保持不变 ，不保存中间位置 。浮窗章节必须与最终落点一致 。百分比仅在拖动浮窗中显示 ，采用一位小数 ，统一显示“61.5%” ，视觉文字及无障碍播报均不添加“约” ；此展示规则不改变内部估算方式 ，不作为已读完成率 。长篇书中仍可能有多个相邻落点显示同一舍入值 ，百分比不承诺逐页分辨率 。
- 松手隐藏浮窗并立即切换到目标章节及目标位置状态 ，不等待正文加载完成 。已缓存时直接定位 ；未缓存时内容区先显示现有加载状态 ，正文就绪后完成章内定位 。最终阅读记录在正文可读且定位完成后保存 。目标与当前位置相同时不执行重复跳转 。
- 轻点空白轨道与拖动采用同一提交规则 ：按下显示预览 ，松手确认跳转 ；系统中断时放弃未提交目标 。点击原位置点仍按第 3 节执行返回 ，不得同时触发轨道跳转 。
- 进度条用于快速接近目标 ，附近内容通过正常翻页或滚动查找 ；不增加精细拖动模式 。
- 不设计移出轨道等主动取消手势 。系统中断手势时放弃未提交的目标 。

## 3. 原位置返回

- 首次开始拖动时 ，立即记录拖动前的位置 ，主滑块移开后显示临时原位置点 ；临时点只用于视觉预览 ，不提供返回操作 。第一次确认跳转时 ，在离开当前正文前记录其精确章节及章内位置 ，由正式返回点接续显示 ，即使目标仍在加载或加载失败也保留 。取消手势或未产生实际跳转时撤销临时点 ；已有正式返回位置不随新拖动覆盖 。仅保留一个返回位置 ，后续等待状态不得覆盖这个可读起点 。
- 同一次菜单展开期间 ，连续拖动跳转 、正常翻页与滚动保留该位置 。用户收起菜单时立即清除返回位置 ，再次打开不再显示旧点 ，下一次拖动以当时位置作为新起点 。
- 若已无正式返回点 ，且按下时上一跳转尚未完成加载与定位 ，本次拖动不显示临时点 ，松手也不创建正式点 。不得从最后成功阅读记录恢复已清除的旧点 ，也不得将待加载目标当作新起点 。即使上一跳转在手势中途完成 ，本次手势仍保持无点 ；下一次从已完成的阅读位置开始拖动时才建立新点 。已有正式返回点不受等待状态影响 。
- 点击原位置点恢复精确页面或正文位置 ，成功后清除标记 ；失败时保留 ，允许重试 。退出本书时清除 。
- 拖动进入原位置吸附范围时轻震一次 ，停留不重复 ；离开后再次吸附可再次反馈 。直接点击原位置点确认返回时也轻震一次 ，键盘或无障碍激活保持一致 。已吸附后的松手与加载完成不额外震动 ，反馈遵循系统触觉设置 。不增加提示文案 、Toast 或弹窗 。
- 原位置点不按距离淡出或隐藏，重叠部分由主滑块覆盖；正式返回位置始终保留独立的键盘与无障碍返回动作，直到菜单收起或返回成功。临时原位置点只用于预览，不提供独立返回操作。
- 轻点正式原位置点的 48 × 48 dp 触区可返回，超过系统手势阈值后转为拖动。触区重叠时，主滑块可见圆形（半径 12 dp）内优先抓取主滑块；可见原位置点（半径 8 dp）及其附近透明触区按命中与圆心距离判定。两个圆心相距不超过 4 dp 时，允许点击返回，即使原位置点被完全覆盖；从主滑块上开始的拖动仍保留抓取偏移，避免滑块跳到手指中心。拖动与直接点击返回不会同时提交。

## 4. 异常与无障碍

- 目录或定位信息不可用时禁用进度操作 。拖动预览不逐次请求章节正文 。
- 加载失败时停留在目标章节的错误状态并支持重试 ，不自动跳回原正文 ；保留最后一次成功阅读记录 ，菜单尚未收起时也保留原位置点供用户返回 。连续请求以最后一次确认目标为准 ，旧请求不得覆盖新位置或保存旧目标 。
- 收起菜单立即禁用进度操作并清除返回点 ，但不取消已确认的加载 ；退出本书后使未完成跳转失效 ，不得迟到更新正文或阅读记录 。
- 系统明暗切换等配置重建保留当前阅读会话 、正文与原位置点 ；只有真正退出阅读时才结束会话 ，重建后重新绑定页面生命周期 。
- 目录更新后按章节身份识别返回目标 ；目标不可用时反馈错误 ，不得返回错误章节 。
- 支持 TalkBack 调整进度 ，播报全书进度及目标章节 。原位置点的无障碍名称为“返回跳转前的阅读位置” 。

## 5. 统计口径与实现细节

以下统计口径已随开发方案确认 ：

- 统计口径 ：首版沿用现有按各章历史最高进度汇总的估算方式 。跳转完成后更新当前阅读位置与目标章节的历史最高进度 ，返回不回滚历史最高进度 ，不批量标记中间跳过的章节 。导航百分比与已读估算分别计算 ，不互相复用 。阅读时长独立累计 ，跳转距离不换算为时长 。精确统计实际读过区间不纳入本次进度条范围 。

实现细节 ：

- 数据不足时的估算页数参数与误差 ，以及分页索引的缓存与失效实现 。需符合第 2 节的真实分页优先 、会话内稳定和章内定位要求 。
- 正文图片计入进度，翻页模式的内置图片组件沿用一图一页规则，滚动模式采用实际布局高度。内置文字支持字符锚点；插件分段接口不暴露源字符偏移时，沿用组件内比例定位。
- 点击与拖动使用系统手势阈值 ，提交行为遵循第 2–3 节 。

## 6. 验收覆盖

按第 1–4 节逐项验收 ，另外覆盖 ：

- 长章节名 、大字体 、浅色与深色主题 ；悬浮面板与系统安全区 、窄屏下的五项按钮布局 ，以及禁用书签和目录视觉重心 。
- 连续拖动经过长短章节名及 0.0%–100.0% ，同一屏宽和字体设置下浮窗宽高 、水平中心及与底栏的间距保持不变 ，标题按内容在固定两行区域内居中 ，百分比行位置固定 ，仅更新文字内容 ，不为跨章添加位移 、缩放或淡入淡出动画 。覆盖一行与两行来回切换 、9.9% → 10.0% → 100.0% ，以及系统 200% 字号 ；网页线性缩放只作样式示意 ，不代替 Android 非线性缩放和真机验证 。
- 现有全部预设主题 、动态配色开启与关闭 、系统不支持动态配色的回退 、明暗切换和自定义纸张背景 ；特别检查底轨与填充 、滑块与原位置点重叠 、浮窗文字的可辨认度 。
- 单章书 、章节长度差异明显的书籍 、空章节及未缓存章节 。
- 同一章内不同落点 、书首书尾 、翻页与滚动模式 。
- 浮窗仅显示章节名及下方弱化的全书目标百分比 ，不显示卷名 ；百分比仅在拖动浮窗中显示 ，覆盖一位小数 、真实与估算映射均不显示或播报“约” ，以及相邻落点舍入值相同的情况 。轨道无常驻数字或数字占位行 ，进度操作行高 52 dp 且保留至少 48 dp 触摸区域 ，浮窗覆盖正文且不撑高底栏 。
- 连续跳转后返回、部分重叠时的可见圆形命中、完全覆盖时仍可点击正式返回点、抓取偏移、独立键盘与无障碍动作、收起再打开菜单无旧返回点、加载失败后返回或重试、请求乱序、等待期间退出本书、手势中断及 TalkBack 操作。
- 估算映射不随后台缓存增加而漂移 ，目录更新后按章节身份恢复目标 。按第 5 节验证导航位置与已读统计的区别 。
